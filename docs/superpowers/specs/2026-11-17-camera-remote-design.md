# ESP32-C6 单键相机遥控器

用户已批准实现和无设备验证；不执行 Git 提交、烧录或实机操作。

## 行为契约

- 普通照片模式短按拍照；普通视频模式短按开始录像，录像中再次短按停止。
- 长按 1500 ms 只产生一次事件，松手不再产生短按。消抖 30 ms。
- 长按时若正在录像，先停录并等待结束；若正在拍照，等待结束；之后发送休眠命令。
- 休眠时第一次短按只唤醒，完成连接和状态同步后下一次短按才拍摄。
- 连接、唤醒、拍摄指令确认和休眠过渡期间不缓存按键；按下时尚未就绪的手势不能在就绪后被当作拍摄。
- 跟随相机模式，不切换模式；第一版只开放模式 0x01 / 0x05，预录制不等同实际录像。
- 屏幕关闭不代表休眠；依据 1D02 的 power_mode。断线后旧状态失效。
- 休眠成功后禁止 GATT 命令；唤醒使用约 2 秒 WKP 广播，随后完整重连、握手、订阅并等待新状态。
- 广播唤醒受官方限制：近期成功连接过且休眠未超过 30 分钟。不保证任意关机时长可唤醒。
- 拍摄 ACK 超时不重发快门，避免重复照片或开始后立即停止。结果不确定时撤销就绪并恢复连接。
- 首次上电搜索近距离支持相机，授权成功后保存目标地址和类型；之后仅连接绑定相机。开发期通过串口清除绑定。

## 实现选择

直接在官方 key_logic 中增加分支改动较小，但阻塞扫描、同步回调和分散状态使休眠行为难以验证。
采用纯 C 控制核心、纯 C 按键识别、固定缓冲协议编解码与 ESP-IDF BLE 适配层。
官方源码保留为参考，生产构建只编译新遥控器和官方 CRC；协议字节格式通过官方样例帧验证。
这是实现时的工程选择，不改变上述用户行为。使用现有 ESP-IDF 6.1.1 / Bluedroid / FreeRTOS。

## 边界与验证

核心只由一个任务更新；BLE 回调只投递有界事件。连接编号阻止旧通知影响新连接。
所有操作有期限；丢队列事件进入恢复状态，不能继续使用可能过期的拍摄状态。
状态机、实际协议帧、消抖与故障恢复在主机运行 ASan/UBSan 测试；ESP32-C6 构建验证适配层。
实机配对、射频、实际文件保存和各型号休眠行为留给用户验证，不用主机测试替代。
